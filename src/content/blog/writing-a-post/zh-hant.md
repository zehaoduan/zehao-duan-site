這是一篇示範文章。它標記為草稿，所以只會在執行 `npm run dev` 時出現，不會出現在正式網站上。要寫第一篇正式文章，請複製這個資料夾，為副本改一個新名稱，然後修改內容。

## 文章的資料夾

資料夾的名稱就是文章的網址：資料夾 `writing-a-post` 對應 `/zh-hant/blog/writing-a-post/`。名稱請用小寫英文字母、數字和連字號。資料夾內有：

- `post.json`，記錄各語言共用的資料；
- `en.md`、`zh-hant.md` 和 `zh-hans.md`，每種語言一個檔案；
- 文章的圖片。

三個語言檔案必須齊全。缺少任何一個，建置就會停止並顯示訊息。

## 文字

段落之間以空行分隔。文字可以*強調*或**加粗**，可以加上[其他網站的連結](https://www.cityu.edu.hk/)，也可以連結到本站的頁面，例如[公鑰](/zh-hant/public-key/)。

文章內的標題由第二級開始，即兩個井號。文章的題目是頁面上唯一的第一級標題。

### 較小的標題

編號清單：

1. 先用英文寫好內容。
2. 翻譯成繁體中文和簡體中文。
3. 在 `post.json` 中設定 `"draft": false`。

> 引文會獨立成段顯示。

## 圖片

把圖片檔案放進文章的資料夾，然後在文中寫上檔案名稱。方括號內的文字是圖片的描述，供看不到圖片的讀者閱讀，必須填寫。引號內的文字會成為圖片說明。

![格線上的兩條衰減振盪曲線。藍色曲線約三個週期後平息，灰色曲線需要更長時間。](figure-1.png "擾動後的響應：阻尼較強（藍）與阻尼較弱（灰）。")

建置時會把圖片縮小至最寬 1600 像素，並轉換為 WebP 格式。原始檔案保持不變。

| 物理量 | 符號 | 單位 |
| --- | --- | --- |
| 頻率 | *f* | Hz |
| 有功功率 | *P* | MW |
| 無功功率 | *Q* | Mvar |

## 文章不能包含的內容

寫在 Markdown 檔案內的 HTML 會被移除，圖片必須是文章資料夾內的檔案。這兩點都源自本站的安全政策。
